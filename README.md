# Exercícios de Python — Lógica e Desenvolvimento

Repositório de exercícios práticos desenvolvidos durante meus estudos de Python. A proposta é registrar a evolução dos fundamentos da linguagem e praticar a resolução de problemas com pequenas aplicações.

## Conteúdo

- Fundamentos da linguagem e lógica de programação.
- Estruturas condicionais e de repetição.
- Listas, dicionários e outras estruturas de dados.
- Funções e modularização.
- Validação de entradas e tratamento de exceções.
- Manipulação de arquivos e dados.
- Introdução à Programação Orientada a Objetos.

## Organização

- `01-basico/` — fundamentos, estruturas de dados, funções e lógica.
- `02-intermediario/` — validações, tratamento de erros e arquivos.
- `03-poo/` — classes, objetos e organização orientada a objetos.
- `04-dados/` — exercícios de leitura e processamento de dados.

## Como executar

Tenha Python instalado e execute no terminal o arquivo desejado:

```bash
python caminho/do/arquivo.py
```

## Objetivo de aprendizagem

Praticar a construção de soluções passo a passo, compreender o fluxo do código e desenvolver autonomia para analisar erros e implementar melhorias.

Este repositório é composto por exercícios de estudo; cada pasta e arquivo deve ser consultado para verificar o escopo efetivamente implementado.
